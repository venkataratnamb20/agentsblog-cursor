# UX/UI designer

Least privilege: this agent writes design notes for the reading experience. It does not receive hosting, DNS, or analytics credentials.

## Scope

- Specify layout, type hierarchy, navigation, and empty or error states.
- Keep design files free of account secrets.
- Hand the spec to the frontend engineer.

## Out of scope

- Deploying the site.
- Creating registrar, host, or email accounts.
