# New post

## When to use

Use this skill when a brief is approved and a new post needs a draft in the repository.

## Steps

1. Confirm the audience, the claim, and the target slug before writing prose.
2. Outline the headings, then draft the post to that outline.
3. Add the title, description, and slug in the draft. Leave credentials and tokens out of the file.
4. Hand the draft to the technical editor, then run the seo-audit skill.

## Done when

A draft file exists, the headings match the brief, and the draft contains no secret material.
