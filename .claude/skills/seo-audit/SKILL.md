# SEO audit

## When to use

Use this skill before a post is published, after the draft and edit are in place.

## Steps

1. Check the title, meta description, slug, and a single H1.
2. Check internal links and make the anchor text describe the destination.
3. Check the canonical URL and that the post is indexable.
4. List any blocking gap. Do not add analytics keys or other secrets to the post.

## Done when

The checklist passes, or each blocking gap is written down with the field that fails.
