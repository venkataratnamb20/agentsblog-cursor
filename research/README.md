# Research library

Local, in-repo reference library for Agents Blog. Papers, notes, and
source lists live in this repository so writers and editors can cite
them without external accounts.

## How notes are stored

Notes are stored in-repo as Markdown under this tree:

| Path | Role |
| --- | --- |
| `research/sources/` | Bibliographic entries and source lists (title, URL, date, claim) |
| `research/packs/` | Per-post or per-topic research packs assembled for writers |

Keep each note short: claim, source, date, and confidence. Do not paste
secrets, credentials, or access tokens into notes. Record that an
action happened; never record secret values.

## Packs

Packs live under `research/packs/`. Another agent or a later task may
add pack files there. This library layout does not invent pack content.

## Zotero and Notion

Zotero and Notion accounts are not created. External sync tools wait
for Venkat approval before any account is opened or paid seat is
bought. Until then, the reference library is Markdown only, in this
repository.

## Out of scope for this layout

- Creating Zotero or Notion accounts
- Storing secrets or credentials
- Publishing posts
