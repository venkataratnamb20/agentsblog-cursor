# Sources

Bibliographic entries and source lists for the in-repo research
library. Add one Markdown note per source (or a dated list) with:

- title
- URL or citation
- date accessed or published
- claim the source supports or contradicts
- confidence (high / medium / low)

Do not put secrets or credentials in these files. Packs that assemble
sources for a post live under `research/packs/`, not here.
