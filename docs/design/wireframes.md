# Wireframes

Text wireframes for the local preview. Nothing in the repository described these screens before. `docs/design/information-architecture.md` links the same paths. User instruction: "Go ahead and complete the next goals. Deploy multiple agents with similar and relevant skills with gitworktree."

The page is a single column, about 40rem wide, in a serif face. A theme button sits after the main text.

## Home

```text
[Home] [Search] [About] [Subscribe] [Privacy]
Agents Blog
Search
- Post title -> /posts/{slug}.html
[Toggle theme]
```

Draft titles are absent. An empty blog still shows the title and the search link.

## Post

```text
[Home] [Search] [About] [Subscribe] [Privacy]
H1 Post title
tag -> /tags/{slug}.html
H2 section
paragraph
[Toggle theme]
```

The body is text. A less-than character is shown as text, not as markup.
