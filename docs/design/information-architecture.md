# Information architecture

There is no public host. Paths below are for the local preview at `http://127.0.0.1:8000`.

## Sitemap

| Path | Page |
| --- | --- |
| `/` | Index of published posts |
| `/search.html` | Search |
| `/about.html` | About the blog and its readers |
| `/subscribe.html` | Subscribe, with no email form |
| `/posts/{slug}.html` | One published post |
| `/tags/{slug}.html` | Posts that share a published tag |
| `/feed.xml` | RSS |
| `/privacy.html` | Privacy draft |
| `/cookies.html` | Cookies draft |
| `/terms.html` | Terms draft |
| `/licences.html` | Licences draft |
| `/ai-assistance.html` | AI assistance draft |
| `/404.html` | Missing page |

Draft posts are not in this map.

## Navigation

Every page shows Home, Search, About, Subscribe, and Privacy. Tag links sit on the post, not in the global nav. Series are a reading order described in the content pillars. They do not have their own URLs yet.

## Taxonomy

A tag is a label on a published post. A series is an ordered list of posts inside one pillar. Pillars are Foundations, Building, Evaluation, Safety, and Operations.
