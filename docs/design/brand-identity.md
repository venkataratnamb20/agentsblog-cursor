# Brand identity

The public site is not live. This document names the brand for the local preview. It does not create a logo file or spend money.

## Name

Agents Blog

## Tagline

Clear writing for people who build AI agents.

## Audience signal

AI engineers, researchers, and tech leads.

## Colour

The local stylesheet already uses this pair:

| Role | Light | Dark |
| --- | --- | --- |
| Page | `#f7f4ef` background, `#1c1915` text | `#1c1915` background, `#f7f4ef` text |

Do not introduce a purple gradient or a second brand palette until a design review says so.

## Typography

Reading text uses Georgia (with Times New Roman as a fallback). The display of the brand name on the index is the same serif face, not a separate display font yet.

## Cover template

A cover is a text layout, not an image asset:

1. Brand name: Agents Blog
2. One post title
3. One short summary line
4. Optional tag names under the summary

No logo mark is required for the local preview. A paid logo or custom typeface waits on Venkat's approval.
